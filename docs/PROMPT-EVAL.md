# 提示词评测与演进记录

这份文档记录 BiliDude 提示词（`lib/llm/prompt.ts`）的评测方法、测试视频清单以及从 v0 到 v3 的实证演进。

评测脚本在 [`eval/`](../eval/README.md)，直接复用扩展的 `runAgent` 和渲染端校验插件（时间戳、逐字引文），确保评测结果和用户在侧栏里看到的完全一致。

## 评判原则

改提示词从产品场景和泛化性出发，而不是对着固定题库刷分：

- **硬性契约不能退步**：时间戳不超出视频时长、引文通过字幕逐字校验、服从用户显式要求的语言或格式、搜索与引用协议正常。
- **风格与体验综合判断**：回答长短、是否加标题、用表格还是列表等主观体验，不做一票否决，由维护者看并排 HTML 报告整体取舍。

## 评测流程

- **回答生成**（`pnpm eval`）：模型用扩展默认的 `deepseek-flash`（思考关闭），每个用例 × 每个版本跑 3 次以抵消随机波动；追问使用第一问的真实回答作为历史。
- **自动指标**（`pnpm eval:report`）：经由扩展的 `remarkTimestamps`、`remarkCitations` 和 `createTranscriptCheck` 统计字数、标题率、表格率、时间戳丢弃率、引文通过率、地球搜索提示率等，并生成并排对比的 `eval/results/report.html`。
- **盲评参考**（`pnpm eval:judge`）：用 `deepseek-v4-pro`（思考开到 medium）做随机左右盲评，评委能看到问题、视频信息和回答引用时间点前后的字幕摘录。盲评结果仅作参考。

## 实验记录（v0 → v3）

### 版本演变

- **v0**（`5d49629`）：早期版本，要求“Markdown with headings”且开头定调为 `a piece of writing, not a chat reply`。
- **v1**（`de09e11`）：把日期挪到用户消息以保前缀缓存，补充逐字引文校验说明和表格规则。
- **vmin**：极简对照，只留身份、输出语言、渲染端依赖的格式契约和视频内容，用来检验哪些风格规则真的在起作用。
- **v2 / v2.1**：尝试解决短问题乱加标题和视频外问题硬扯视频。v2 删掉 `not a chat reply` 和 `with headings`、新增搜索关着时的地球图标提示；v2.1 为补救 v2 的表格退步，在开头硬补了一句“不论长短比较项目都用表格”。
- **v3a / v3b / v3c**：回到产品场景和原因重写——明确用户会把视频拿来做从快速解惑到深度总结、对比、改写和延伸提问的各类任务；解释每条硬规则背后的原因（时间戳变跳转按钮、引文自动校验）；明确“多对象同维度对比用表格，顺序步骤或单维度清单用列表”；语言规则显式服从用户指定语言。
  - `v3a`：纯场景和原因定调，预设不变。
  - `v3b`：仅把开头改回保留 v1 的 `not a chat reply` + 例外条款，与 `v3a` 单变量对照。
  - `v3c`：在 `v3a` 基础上补齐细节（允许章节时间、区分服务端/客户端搜索的 `[n]` 引用规则、搜索语言与停止指引、`toc` 4–10 章弹性指引）。最终以 `v3c` 为底本（微调搜索关着时先交代视频已有线索）合入 `lib/llm/prompt.ts`。

### 踩过的坑与结论

1. **整体定调压过局部规则**：`v1` 的 `not a chat reply` + `with headings` 让它写长文、表格、引文都稳，但也让短问题乱加标题、视频外问题硬塞时间戳。`v3b` 验证了即使把短问题写成例外，`not a chat reply` 仍会让短问题回冒标题（12%），并把“提醒点地球图标”从 100% 压到 56%。
2. **对着题库打补丁会过拟合**：`v2.1` 为了把 4 道表格题从 63% 拉回 95%，在开头硬加了一句表格提示，结果让英文列步骤题（`4-english`）也开始画表格（20%–60%）。`v3` 改为讲清“多对象同维度对比用表格、步骤和单维度清单用列表”后，`4-english` 表格率归零。
3. **极简对照的价值**：`vmin` 证明去掉 `with headings` 后短问题标题几乎自然消失（5%），而去掉表格规则后模型完全不出表格（0%），从而明确了哪些规则该留、哪些在帮倒忙。
4. **评委偏见与单样本波动**：第一轮盲评说明里写了“窄侧栏”，导致评委反过来扣表格的分（`v0` 一张表格没有却在表格类 4:0 赢 `v1`）。此外单样本盲评方差很大（`v2.1` 预设第 1 次 2:6，补到 3 次后是 14:10），因此盲评只能配合自动指标和人工抽检一起看。
